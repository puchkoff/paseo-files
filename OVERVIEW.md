Paste files into an agent composer with Ctrl+V / Cmd+V. Copy a PDF, a log, an archive or any other file (in your file manager, or from another app) and paste it into the chat input: it is attached as a file, the same as dragging it onto the chat.

Paseo already pastes images; this plugin adds every other file type. It works in the web and desktop apps, as long as the browser puts the copied file on the clipboard (Chrome and the desktop app do for files copied in Finder and Explorer; some Linux file managers copy only the path).
